# Project Identity

- **Name**: Mindroot (Student to Student Knowledge & Skill Sharing Platform)
- **Stack**:
  - Frontend: React 18, Vite, TypeScript, TailwindCSS, Zustand, Lucide/Material Icons, Socket.IO Client
  - Backend: Node.js, Express, TypeScript, Socket.IO, Prisma ORM, PostgreSQL (with in-memory fallback store)
- **Entry Points**:
  - Frontend: `src/main.tsx`, `src/App.tsx`
  - Backend: `server/src/index.ts`
  - Database Schema: `server/prisma/schema.prisma`
- **Commands**:
  - Dev Frontend: `npm run dev`
  - Dev Server: `npm run server`
  - Typecheck: `npx tsc --noEmit`
  - Build: `npm run build`
